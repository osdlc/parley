# parley

parley turns a document an AI agent writes into a review page for a person. The document is JSON:
a list of typed blocks (prose, questions, schemas, diffs, diagrams, plans and more) and the
questions the agent needs answered. parley serves it as one page. The person reads it, comments on
any part and answers the questions. Their answers land in a JSON file beside the document, and the
agent reads them back and replies.

This repository is the parley plugin marketplace. It holds the built plugin for four agent
harnesses and nothing else. The skill's `parley.mjs` is one bundled file that runs under Node 22
or later, bun or deno, with nothing else to install.

Version 0.2.1. The plugin id is `parley@parley`.

## Skills

| Skill | What it does |
| --- | --- |
| `parley` | Check, serve and render any parley document, and read the reviewer's answers back. The others use it. |
| `code-review` | Review a change (the working tree, a branch or a range) as a diff with findings on its lines. |
| `pr-review` | Review a GitHub pull request the same way, with its checks. Posts to the PR only when the reviewer says so. |
| `discuss` | Put a design question to the reviewer: options, tradeoffs, a recommendation and the decision. |
| `plan` | Write a work plan the reviewer approves or sends back before the work starts. |

In Claude Code a skill runs as `/parley:<skill>`, such as `/parley:pr-review 42`. In Pi it is
`/skill:parley-<skill>`.

## Install

### Claude Code

```sh
claude plugin marketplace add osdlc/parley
claude plugin install parley@parley
```

In a session, the same is `/plugin marketplace add osdlc/parley`, then
`/plugin install parley@parley`.

### Codex

```sh
codex plugin marketplace add osdlc/parley
codex plugin add parley@parley
```

### Cursor

Add the marketplace to your Cursor account from its git URL:

```sh
cursor-agent plugin marketplace add https://github.com/osdlc/parley
```

`cursor-agent` has no install command. Install `parley` in the Cursor app, which lists the plugins
of the marketplaces on your account.

### Pi

Pi installs a package from a folder. Clone this repository, then install the pack in it:

```sh
git clone https://github.com/osdlc/parley
pi install ./parley/.pi/packs/parley
```

`pi install` records the clone's path, and `pi list` shows it, so keep the clone where it is.

Every file on `main` is generated by the parley release, and a file added here by hand is removed
by the next release. Changes to parley are made in its source repository, which is private, and
released here.
