parley

parley shows an agent's plan as a page. You answer its questions there, and it reads your answers from a file.

npm i -g @osdlc/parley

How it works

  1. Write. The agent writes a document as JSON.
  2. Check.parley check rejects a broken document.
  3. Review. You comment and answer its questions on one page.
  4. Read back. The agent reads your answers from a JSON file and revises.

The problem

  • An agent’s plan arrives as long markdown in chat.
  • Its questions are buried in the text.
  • Your answer goes back as a paragraph the agent has to read.
  • Nothing is kept when the session ends.

What parley is

  • The agent writes a document as JSON. You review it as one page.
  • Comment on any part. Answer typed questions.
  • Your answers go to a JSON file next to the document.

The loop

  • The agent writes the document and runs parley check.
  • parley serve shows the page. parley open prints its link.
  • You answer, then press Finish review: Approve or Request changes.
  • The agent reads parley answers, replies in a thread and revises. The page updates in place.

Block types

  • 20 block types: prose, question, diff, matrix, table, checklist, schema, plan, sequence and flow diagrams, and more.
  • Prose tones, console and log output, image regions.

Why typed

  • A choice is an option id, not a paragraph.
  • Answers survive when the agent rewrites the document.
  • parley check rejects a broken document before you see it.
  • The agent edits by item id: get, set, add, remove, move, apply.

Install and agents

  • npm i -g @osdlc/parley
  • No runtime dependencies. Node 22 or later.
  • Any agent that can write a JSON file and read one. Skill packs for Claude Code, Cursor and Codex.
  • Wrapper skills today: discuss, explain, decision-make and review-pr --page.
The npm line is true only once the package is published.

Status

  • Alpha. The file format may change.
  • One reviewer at a time.
  • Runs on your machine. The server binds to loopback unless you pass --host.
  • Sharing a review is in design, not built.
